# 九九乘法挑戰遊戲

這是一個互動式的九九乘法練習遊戲，適合學生練習乘法表。

## 功能特色

- **兩種挑戰模式**：
  - 時間挑戰：在 60 秒內盡可能答對更多題目
  - 題數挑戰：自選題數（5、10、30 題或自訂）

- **自訂練習範圍**：可選擇要練習的乘法表（2-9），支援複選

- **即時回饋**：答對顯示鼓勵訊息，答錯顯示正確答案

- **錯題練習**：遊戲結束後可針對答錯的題目進行練習

- **排行榜系統**：儲存前 10 名成績，支援時間挑戰和題數挑戰兩種排行榜

- **可愛動物圖示**：每道題目隨機顯示可愛動物圖案

- **背景音樂**：輕鬆的遊戲背景音樂

## 使用方式

1. 直接用瀏覽器開啟 `index.html` 即可遊玩
2. 或使用任何靜態網頁伺服器托管此專案

## 技術栈

- HTML5
- CSS3（包含動畫效果）
- JavaScript（ES6+）
- LocalStorage（用於儲存排行榜）

## 操作說明

1. 選擇挑戰模式（時間或題數）
2. 選擇要練習的乘法表（可複選）
3. 若選擇題數挑戰，需選擇題數
4. 點擊「開始遊戲」
5. 使用數字鍵盤輸入答案
6. 遊戲結束後可查看成績和排行榜
